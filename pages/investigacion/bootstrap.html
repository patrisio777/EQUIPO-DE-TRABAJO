Bootstrap

Framework CSS que facilita la creación de sitios web responsivos y modernos.

¿Qué es Bootstrap?

Un framework CSS de código abierto creado por Twitter.

Bootstrap es un framework de CSS y JavaScript que proporciona componentes prediseñados, un sistema de grillas responsivo y utilidades para crear sitios web de forma rápida y consistente.

En lugar de escribir todo el CSS desde cero, Bootstrap ofrece clases listas para usar que aplican estilos profesionales con solo agregarlas al HTML.

Fue creado por ingenieros de Twitter en 2011 y actualmente es uno de los frameworks más utilizados en el mundo.

Ventajas de usar Bootstrap
  • Rapidez: no necesitas escribir CSS desde cero
  • Responsivo: se adapta automáticamente a cualquier pantalla
  • Consistencia: todos los componentes tienen un diseño coherente
  • Documentación: tiene una documentación muy completa en getbootstrap.com
  • Comunidad: millones de desarrolladores lo usan y comparten soluciones

Diseño Responsivo

Un solo sitio que se adapta a cualquier dispositivo.

Móvil

Menor a 768px. Las columnas se apilan verticalmente.

col-12 (por defecto)
Tablet

Desde 768px. Se activan las clases col-md-*.

col-md-6
Escritorio

Desde 992px. Se activan las clases col-lg-*.

col-lg-4

Dato: El diseño responsivo significa que el sitio se adapta automáticamente al tamaño de la pantalla sin necesidad de crear versiones separadas para móvil y escritorio.

Sistema de Grillas

La base de Bootstrap: container, row y col.

¿Cómo funciona?

Bootstrap divide la pantalla en 12 columnas. Tú decides cuántas columnas ocupa cada elemento:

col-12 → 100% del ancho
col-6 → 50%
col-6 → 50%
col-4 → 33%
col-4 → 33%
col-4 → 33%
col-3 → 25%
col-3 → 25%
col-3 → 25%
col-3 → 25%

Estructura básica

Siempre necesitas estas tres capas:

<div class="container">      ← centra el contenido
  <div class="row">            ← crea una fila
    <div class="col-md-6">    ← columna (mitad en tablet+)
      Contenido aquí
    </div>
    <div class="col-md-6">    ← otra columna
      Más contenido
    </div>
  </div>
</div>

Componentes Reutilizables

Elementos prediseñados que usas con solo agregar clases CSS.

Navbar

Barra de navegación responsiva que se colapsa en móvil con un botón hamburguesa.

Clases: navbar, navbar-expand-lg, navbar-toggler

Usado en: Todas las páginas del sitio

Cards (Tarjetas)

Contenedores con borde, título y cuerpo para presentar información agrupada.

Clases: card, card-body, card-title

Usado en: Integrantes, fortalezas, enlaces destacados

Botones

Botones con estilos predefinidos para acciones principales y secundarias.

Clases: btn, btn-primary, btn-outline-light, btn-lg

Dropdown

Menú desplegable que muestra opciones al hacer clic.

Clases: dropdown, dropdown-toggle, dropdown-menu, dropdown-item

Usado en: Menú "Investigación" de la navbar

Badges

Etiquetas pequeñas para resaltar información como roles o estados.

Clases: badge, bg-primary, bg-success, bg-warning

Primary Success Warning Danger Info
Alertas

Mensajes destacados para informar, advertir o confirmar acciones.

Clases: alert, alert-info, alert-success, alert-warning

Bootstrap vs CSS Personalizado

¿Cuándo usar cada uno?

Bootstrap
  • Componentes listos para usar (navbar, cards, botones)
  • Sistema de grillas responsivo
  • Utilidades rápidas (márgenes, padding, flexbox)
  • Ideal para estructura y layout general
  • Mismo diseño base en todos los navegadores
CSS Personalizado
  • Colores y tipografías propias del equipo
  • Estilos únicos que Bootstrap no ofrece
  • Personalizar componentes de Bootstrap
  • Identidad visual propia del sitio
  • Control total sobre cada detalle

En nuestro sitio: Usamos Bootstrap para la estructura (grillas, navbar, cards) y nuestro archivo css/styles.css para los colores, tipografías y estilos propios de GADC.
