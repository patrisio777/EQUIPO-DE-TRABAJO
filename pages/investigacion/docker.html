Docker Desktop y Comandos

Contenedores, flujo de publicación con Nginx y referencia de comandos CLI.

¿Qué es Docker Desktop?

Entorno local para la creación y ejecución de contenedores.

Docker Desktop es una herramienta gráfica integral que permite construir, ejecutar y gestionar contenedores Docker localmente. Integra el motor Docker Engine, la interfaz de línea de comandos (CLI) y un entorno optimizado para Windows mediante WSL 2 (Windows Subsystem for Linux), eliminando las discrepancias entre entornos de desarrollo y producción.

WSL 2 Backend

Permite ejecutar el demonio de Linux de forma nativa en Windows con alto rendimiento y bajo consumo de recursos.

Publicación con Nginx y Dockerfile

Empaquetado y distribución de la aplicación estática.

Para servir nuestro sitio web estático utilizamos Nginx, un servidor web de alto rendimiento y bajo consumo de memoria. Empaquetamos el código mediante el siguiente Dockerfile:

Dockerfile
FROM nginx:alpine
COPY . /usr/share/nginx/html
EXPOSE 80

Comandos Principales de Docker

Referencia técnica de comandos CLI aplicados en el laboratorio.

Comando Sintaxis General Descripción Ejemplo Práctico Caso de Uso / Resultado
docker --version docker --version Muestra la versión del motor de Docker instalada. docker --version Verifica que el CLI esté en el PATH del sistema.
docker run hello-world docker run [opciones] imagen Descarga y corre una imagen de verificación. docker run hello-world Comprueba la comunicación con Docker Hub y el daemon.
docker images docker images Lista todas las imágenes almacenadas localmente. docker images Revisa el tamaño y los IDs de las imágenes creadas.
docker ps docker ps Lista exclusivamente los contenedores en ejecución. docker ps Comprueba si el servidor web sigue arriba.
docker ps -a docker ps -a Muestra todos los contenedores (activos y detenidos). docker ps -a Identifica contenedores caídos o que finalizaron.
docker build docker build -t nombre:tag ruta Construye una imagen a partir de un Dockerfile. docker build -t mi-web . Crea la imagen personalizada para el sitio web.
docker run docker run [flags] imagen Instancia y arranca un contenedor nuevo. docker run -d -p 8080:80 mi-web Despliega la aplicación en segundo plano.
docker stop docker stop [ID/Nombre] Envía señal SIGTERM para detener el contenedor de forma segura. docker stop contenedor-web Detiene el servidor temporalmente.
docker start docker start [ID/Nombre] Reactiva un contenedor que estaba detenido. docker start contenedor-web Vuelve a levantar la web sin recrear el contenedor.
docker rm docker rm [ID/Nombre] Elimina uno o más contenedores detenidos. docker rm contenedor-web Libera nombres de contenedores y espacio en disco.
docker rmi docker rmi [ID/NombreImagen] Elimina imágenes locales del sistema. docker rmi nginx:alpine Limpia imágenes antiguas o en desuso.
docker logs docker logs [ID/Nombre] Muestra la salida estándar y errores del contenedor. docker logs contenedor-web Depura errores de arranque o peticiones HTTP recibidas.
docker exec docker exec -it [ID] comando Ejecuta un comando interactivo dentro del contenedor. docker exec -it contenedor-web sh Abre una terminal interna en el contenedor para inspección.
