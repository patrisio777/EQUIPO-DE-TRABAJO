Etiquetas HTML de Uso Común

Elementos esenciales para estructurar texto, multimedia, datos tabulares y formularios interactivos.

Encabezados y Texto: <h1> a <h6> y <p>

Definen la jerarquía de lectura y los bloques de información.

<h1> a <h6> (Headings)

Cuándo usar: Para jerarquizar los títulos del documento. Solo debe existir un <h1> principal por página; <h2> para secciones mayores y de <h3> a <h6> para subsecciones anidadas.

<h1>Título Principal</h1>
<h2>Subtítulo de Sección</h2>
<p> (Paragraph)

Cuándo usar: Para estructurar cualquier bloque de texto regular, descripciones continuas o explicaciones teóricas.

<p>Texto descriptivo del perfil del integrante.</p>

Recursos y Multimedia: <a> e <img>

Permiten la navegación entre documentos y la integración gráfica.

<a> (Anchor / Enlace)

Cuándo usar: Para crear hipervínculos internos entre páginas del sitio o externos hacia repositorios y recursos web mediante el atributo href.

<a href="https://github.com/..." target="_blank">Ver GitHub</a>
<img> (Image)

Cuándo usar: Para insertar imágenes en el documento. Exige siempre el atributo src (origen) y alt (descripción textual para accesibilidad).

<img src="../../images/foto.jpg" alt="Foto de perfil" class="img-fluid">

Listas: <ul>, <ol> y <li>

Agrupación de elementos con o sin orden secuencial.

<ul> (Unordered List)

Cuándo usar: Para listas de elementos con viñetas donde el orden de los elementos no altera el sentido.

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
</ul>
<ol> (Ordered List)

Cuándo usar: Para listas numeradas donde el orden secuencial o cronológico es estricto e indispensable.

<ol>
  <li>Descargar Docker</li>
  <li>Instalar WSL 2</li>
</ol>
<li> (List Item)

Cuándo usar: Exclusivamente dentro de un contenedor <ul> u <ol> para representar cada ítem individual.

<li class="nav-item">Inicio</li>

Contenedores Genéricos: <div> y <span>

Elementos de agrupación sin significado semántico nativo para maquetación y estilos.

<div> (Division - Bloque)

Cuándo usar: Como contenedor a nivel de bloque para agrupar otros elementos y aplicar clases de maquetación de Bootstrap o estilos CSS (márgenes, grillas, sombras).

<div class="row justify-content-center">...</div>
<span> (En línea)

Cuándo usar: Para aislar una palabra o fragmento de texto dentro de una línea y aplicarle un estilo visual concreto sin generar un salto de bloque.

<span class="badge bg-primary">Frontend</span>

Tablas de Datos: <table>

Estructuración de datos tabulares bidimensionales.

<table>, <thead>, <tbody>, <tr>, <th>, <td>

Cuándo usar: Para representar datos que tienen relación de filas y columnas (matrices, comparaciones de comandos, rúbricas). No debe usarse para maquetar el diseño de la página.

<table class="table">
  <thead><tr><th>Encabezado</th></tr></thead>
  <tbody><tr><td>Dato</td></tr></tbody>
</table>

Formularios e Interacción: <form>, <label>, <input> y <button>

Captura de datos del usuario y ejecución de acciones interactivas.

<form> y <label>

Cuándo usar: <form> envuelve controles de entrada para capturar y enviar datos. <label> asigna un texto descriptivo a un campo mediante el atributo for vinculado al id del input.

<form>
  <label for="nombre">Nombre:</label>
  <input id="nombre" type="text">
</form>
<input> y <button>

Cuándo usar: <input> permite ingresar datos (texto, email, contraseñas, checks). <button> desencadena acciones, envíos de formulario o despliegues interactivos.

<input type="email" class="form-control mb-2" placeholder="correo@ejemplo.cl">
<button type="submit" class="btn btn-primary">Enviar</button>

Resumen

Mapeo de etiquetas de uso común aplicadas en el proyecto GADC.

Etiqueta Propósito Dónde se usó en el sitio
<h1> a <h6> Encabezados y jerarquía de títulos. Títulos principales en la sección Hero (<h1>), títulos de secciones (<h2>) y tarjetas de perfiles (<h3>, <h5>).
<p> Párrafos de texto regular. Explicaciones teóricas en páginas de investigación, descripciones de integrantes y subtítulos.
<a> Hipervínculos internos y externos. Enlaces del menú de navegación, botones de regreso/siguiente en perfiles y enlace a GitHub en el footer.
<img> Inserción de imágenes y recursos gráficos. Fotografías de los integrantes en la vista general y en sus perfiles individuales.
<ul> Listas no ordenadas con viñetas. Menú de navegación (.navbar-nav), listas de beneficios e intereses en las tarjetas de perfil.
<li> Elementos individuales de una lista. Cada opción dentro de las listas de navegación y bloques de información técnica.
<div> Contenedor genérico de bloque. Sistema de grillas de Bootstrap (container, row, col-*) y cajas de contenido (border-box).
<span> Contenedor genérico en línea. Insignias de roles técnicos (badge, badge-rol-atardecer) e icono del botón responsive.
<table> Estructuración de datos tabulares. Tablas comparativas y cuadros resumen en las secciones de investigación.
<button> Botón interactivo de acción. Botón hamburguesa responsive de la barra de navegación (navbar-toggler).
