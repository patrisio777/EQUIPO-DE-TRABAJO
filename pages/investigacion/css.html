Cascading Style Sheets

El lenguaje que define la presentación visual, el diseño y la adaptabilidad de las aplicaciones web.

¿Qué es CSS y cuál es su Importancia?

La base del diseño y la experiencia visual en la web.

CSS (Cascading Style Sheets) es un lenguaje declarativo utilizado para describir cómo se representan visualmente los documentos estructurados en HTML.

Permite controlar colores, tipografías, alineaciones, espaciados, bordes, animaciones y la adaptación a diferentes tamaños de pantalla (diseño responsivo).

El concepto de cascada define cómo se resuelven los conflictos cuando varias reglas de estilo apuntan al mismo elemento, considerando la especificidad, la herencia y el orden de declaración.

Importancia en el Desarrollo Web
  • Separación de responsabilidades: Aísla el contenido (HTML) de la presentación visual (CSS).
  • Mantenibilidad: Permite actualizar el diseño completo del sitio modificando una sola hoja de estilos centralizada.
  • Consistencia: Asegura un aspecto visual uniforme en todas las páginas del sistema.
  • Experiencia de usuario (UX): Optimiza la jerarquía visual, la legibilidad y la usabilidad en cualquier dispositivo.

Contenido, Estructura y Presentación

Las tres capas fundamentales en la construcción de interfaces web.

Capa Tecnología Propósito / Responsabilidad Ejemplo en el Proyecto
Contenido Texto, imágenes, datos Información pura que se entrega al usuario final. Datos del integrante, misión del equipo.
Estructura HTML5 semántico Organización lógica, jerarquía y significado del contenido. <header>, <nav>, <main>, <section>
Presentación CSS3 / Bootstrap Aspecto estético, paleta de colores, fuentes y maquetación responsiva. styles.css, clases card, btn-primary

Buenas prácticas: Mantener estas tres capas separadas facilita el trabajo colaborativo en Git y reduce la deuda técnica del código.

Formas de Aplicar CSS

Métodos para vincular estilos a un documento HTML.

CSS en Línea (Inline)
No recomendado

Se aplica directo en el elemento mediante el atributo style="...". Mezcla contenido con presentación y dificulta el mantenimiento.

<h1 style="color: blue;">Título</h1>
CSS Interno
Uso puntual

Se declara dentro de la etiqueta <style> en el encabezado <head>. Útil para prototipos rápidos o estilos exclusivos de una página.

<style>
 p { color: #333; }
</style>
CSS Externo
Estándar recomendado

Hojas de estilo independientes vinculadas con <link>. Permite reutilizar reglas en todo el sitio y aprovecha la memoria caché del navegador.

<link rel="stylesheet" href="../../css/styles.css">

Selectores Básicos, Clases e IDs

Mecanismos para apuntar a elementos específicos del DOM.

Selectores Básicos
  • Universal (*): Aplica a todos los elementos del documento. Muy usado para normalizar cajas (box-sizing: border-box).
  • De Etiqueta (h1, p, a): Aplica a todas las ocurrencias de ese tipo de etiqueta.
  • Combinados / Descendientes (div p, .card > .card-body): Aplican cuando un elemento está anidado dentro de otro.
Clases (.) vs Identificadores (#)
  • Clase (.nombre-clase): Diseñada para reutilizarse en múltiples elementos HTML. Es el pilar del diseño modular y de Bootstrap.
  • Identificador (#nombre-id): Debe ser estrictamente único por página. Posee una especificidad alta y se emplea para destinos de anclaje (enlaces internos) o interacción JavaScript.

Modelo de Caja (Box Model)

Estructura rectangular que envuelve cada elemento HTML.

Margin (Margen externo)
Border (Borde)
Padding (Relleno interno)
Content (Contenido real)
Capas del Modelo
  • Content: El área central donde se renderiza el texto, imagen o elemento.
  • Padding: Espacio interior transparente entre el contenido y el borde.
  • Border: Línea que delimita el padding y el contenido; configurable en grosor, estilo y color.
  • Margin: Espacio exterior transparente que separa el elemento de sus vecinos en la página.

Estilos Propios Aplicados en el Proyecto

Implementación técnica de CSS en nuestro sitio web.

Fondo y Paleta Sunset

Definición de .bg-pattern mediante un degradado lineal combinado con gradientes radiales puntuales, junto con utilidades de color corporativo como .text-sunset-dark (#2d1a29) y .text-sunset-slate (#5c4340).

.bg-pattern, .text-sunset-dark
Hero y Botón Agrandado

La clase .hero-texto-box implementa efecto de desenfoque de fondo (backdrop-filter: blur(4px)), acompañada por el botón de acción .btn-hero-agrandado con transiciones suaves y sombra profunda.

.hero-texto-box, .btn-hero-agrandado
Contenedores y Destaques

Uso de .seccion-contenedor y .border-box con bordes cálidos (#e7d0c5) para encapsular las vistas, además de .card-mision con un acento lateral terracota (#c85a32) en los puntos clave.

.seccion-contenedor, .card-mision
Botones y Badges Propios

Sobreescritura de interacciones visuales mediante .btn-sunset-primary, .btn-sunset-secondary, .btn-outline-sunset y las etiquetas .tech-tag para categorizar herramientas sin depender de los colores por defecto de Bootstrap.

.btn-sunset-primary, .tech-tag
Maquetación de Integrantes

Clases dedicadas para los perfiles individuales como .tarjeta-perfil-contenedor, los marcos de fotos .caja-foto-perfil y las barras de datos .bloque-info-item con borde izquierdo destacado.

.caja-foto-perfil, .bloque-info-item
