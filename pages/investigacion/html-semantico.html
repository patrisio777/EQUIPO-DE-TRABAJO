Etiquetas Semánticas en HTML5

Estructuración lógica y accesible para aplicaciones web modernas.

¿Qué es el HTML Semántico?

Dar significado y jerarquía a la estructura del documento.

El HTML semántico consiste en utilizar etiquetas cuyo nombre describe claramente su propósito y el tipo de contenido que albergan, tanto para el desarrollador como para el navegador y las tecnologías de asistencia.

A diferencia de los contenedores genéricos (como <div> y <span>) que no aportan información contextual, las etiquetas semánticas definen la arquitectura estructural del sitio web, mejorando la accesibilidad y el posicionamiento web.

Beneficios Principales
  • Accesibilidad: Permite a los lectores de pantalla navegar el sitio de forma lógica para personas con discapacidad visual.
  • SEO Técnico: Facilita a los motores de búsqueda indexar e interpretar la jerarquía de la información.
  • Mantenibilidad del Código: Hace que el código sea limpio, legible y fácil de entender por el equipo de desarrollo.

Etiquetas Semánticas Clave

Propósito, sintaxis y su uso dentro del sitio web de GADC.

<header>

Representa un contenedor para contenido introductorio o un conjunto de enlaces de navegación.

<header>
  <nav>...</nav>
</header>
<nav>

Define una sección del documento destinada exclusivamente a enlaces principales de navegación.

<nav class="navbar">
  <a href="index.html">Inicio</a>
</nav>
<main>

Delimita el contenido central y exclusivo del documento, excluyendo cabeceras y pies de página.

<main>
  <section>...</section>
</main>
<section>

Representa una sección temática autónoma dentro del documento.

<section class="seccion">
  <h2>Título</h2>
</section>
<article>

Composición independiente que tiene sentido completo por sí misma (tarjetas de presentación o artículos).

<article class="card">
  <h3>Perfil Integrante</h3>
</article>
<aside>

Información relacionada tangencialmente con el contenido principal (notas secundarias o advertencias).

<aside class="alert alert-info">
  <p>Nota rápida</p>
</aside>
<footer>

Pie de página con información de autoría, derechos de autor o enlaces externos.

<footer>
  <p>GADC - Laboratorio 01 | <a href="...">GitHub</a></p>
</footer>

Resumen

Mapeo de etiquetas semánticas aplicadas en el proyecto GADC.

Etiqueta Propósito Semántico Dónde se usó en el sitio
<header> Encabezado del documento y contenedor de barra superior. En la parte superior de todas las páginas del sitio.
<nav> Sección con enlaces directos de navegación. Menú principal de navegación con Bootstrap (Inicio, Integrantes, etc.).
<main> Área de contenido central y único del documento. Cuerpo principal entre el header y el footer en cada archivo HTML.
<section> Bloques temáticos independientes. Sección Hero, secciones blancas y grises de contenido.
<footer> Pie de página con autoría y enlaces. Base de todas las páginas con la información del equipo y enlace al repositorio.
